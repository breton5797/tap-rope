# 칼퇴근 대작전 (office) — art sources

All images generated on 2026-10-29 with the Higgsfield CLI (`higgsfield generate create`), model **Nano Banana 2** (`nano_banana_flash`, 1k).
AI-generated for the fictional company 야근상사: no real people, brands, logos or baked-in text. No third-party assets.

## Shared prompt pieces

- `STYLE` = `bright Korean webtoon comic style, cute chibi characters 2-2.5 heads tall, bold clean outlines, pastel base colors with neon accent pops, exaggerated funny expressions, manga speed lines, no text, no letters, no logos`
- Prompts below are shown with `STYLE` abbreviated as `$STYLE`.

## Consistency workflow

- One reference per hero (`ref-kid2`, `ref-cat2`, not shipped) and one idle image per superior (shipped as `boss-<slot>.webp`) were approved first.
- Every other hero/boss frame, cutscene and portrait passes those images as `--image-references` (Nano Banana 2 reference editing).

## Post-processing (scripts in the art job tmp dir, reproduced here)

- **Sprites** (heroes, bosses, props): generated on pure white; local cut-out = flood-fill of near-white pixels connected to the border (bold outlines protect interior whites), large pure-white enclosed gaps removed, specks/speed lines < 0.6 % of the largest part dropped, 2 px feathered edge. No Higgsfield background remover was used for shipped files.
  - heroes: trimmed, placed on **512×640** transparent canvas, centred, opaque bottom on the bottom edge (feet anchor = bottom-centre). Upright frames scaled to 610 px subject height (win 620, jump 560); slide scaled to 500 px width.
  - bosses: trimmed, contained in **768×1024** with 8 px margin, bottom-aligned (matches `boss-art.ts`, which trims again).
  - props: trimmed, contained and centred in **512×512** with 8 px margin.
- **Walls** 16:9 → centre crop 1.6:1 → 1024×640; per theme the outer 64 px blend into a shared per-row edge profile so variants a/b/c butt together.
- **Floors** 21:9 → centre crop 2:1 → 1024×512, contrast softened toward the mean, mirrored in x and y (seamless).
- **Ceilings** 21:9 → 4:1 band (centre; ceiling-2 top) → 1024×256, mirrored in x.
- Cutscenes / title / select 9:16 → 1080×1920; zone cards 16:9 → 1280×720 (stage n = `zone-(n−1)`, renamed in ee31ded); portraits centre-cropped 2:3 → 600×900. `cut/boss-5-c` was cropped above a blank white strip first.
- Encoding `cwebp -q 82 -m 6 -sharp_yuv` (scenes 80, cutscenes/title 78).
