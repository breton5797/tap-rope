# 칼퇴근 대작전 (OFFICE ESCAPE: 18:00) — 프로토타입 설계서

> 작성 2026-10-29 · 브랜치 `feat/office-escape` · 기반: LASER ESCAPE v8 (main 7aa1f2d)
> 상태: 대표님 승인 대기. 승인 전에는 코드·아트 생성 없음.

## 1. 의도와 이유

레이저 탈출작전 v8의 조작(3레인 러너, 탭 = 점프, ↓ 스와이프 = 슬라이드, ←→ 스와이프 = 레인 이동)은 그대로 쓴다.
그 위에 **스파이 탈출 이야기를 "귀여운 말단사원의 칼퇴근 탈출 코미디"로 다시 입힌다.**
비유하면 같은 놀이기구에 새 테마파크 옷을 입히는 것이다. 레일(판정·물리)은 그대로 두고 탑승 경험(이야기·캐릭터·연출·아트)을 바꾼다.

핵심 재미는 두 가지다(대표님 요청).
1. **상관마다 깜놀 공격**: 대리부터 사장님까지 직급마다 성격이 드러나는 기습 공격이 있다.
2. **예측불가 요소**: 같은 단계를 다시 해도 돌발 사건과 공격 변형이 달라진다.

먼저 **1~5단계만 프로토타입으로 만든다.** 반응이 좋으면 확장한다.

## 2. 대표님이 결정한 사항

| 항목 | 결정 |
|---|---|
| 배포 | v8(`/tap-rope/`)은 그대로 둔다. 칼퇴근판은 같은 저장소의 **별도 주소 `/tap-rope/office/`** 에 둔다 |
| 상관 배치 | **직급 계단식**: 1 대리 → 2 과장 → 3 팀장 → 4 부장 → 5 임원층(전무·이사가 중간 보스, 사장님이 최종 보스) |
| 주인공 | 남자 사원과 여자 사원 중 **시작할 때 한 명 선택** |
| 온라인 | **오프라인 프로토타입**. 서버·리더보드를 쓰지 않고 기록은 기기에만 저장한다 |
| 아트 | **힉스필드**로 코믹 장르 디자인 |
| 범위 | 1~5단계 |

## 3. 목표 · 비목표 · 반목표

**목표**
- 5단계를 처음부터 끝까지 깰 수 있고, 첫 판부터 웃음이 나는 프로토타입
- 상관 7명이 각자 **말풍선 대사 + 깜놀 등장 + 고유 공격 2~3종**을 가진다
- 매 판 달라지는 돌발 사건과 공격 변형(시드 기반)
- 남녀 사원 2명. 그림 기반 캐릭터로 달리기·점프·슬라이드·레인 이동·피격·성공 동작을 한다
- iPad·휴대폰 웹에서 바로 플레이

**비목표 (확장 단계로 미룬다)**
- 6단계 이상, 무한 모드·데일리, 온라인 리더보드, 상점·결제, 광고, 업적 확장, 앱스토어 출시
- 주인공 꾸미기(의상 상점)

**반목표 (기술적으로 돌아가도 실패로 본다)**
- 깜놀이 **불공정 사망**이 되는 것. 예고 없이 피할 수 없는 공격은 절대 금지
- 실존 회사·브랜드·실존 인물을 닮게 그리는 것. 직장 내 괴롭힘을 미화하거나 특정 성별·연령을 비하하는 개그
- 지금 서비스 중인 v8이 깨지는 것(주소·저장 데이터·리더보드·기록 검증)

## 4. 스토리

**제목**: 칼퇴근 대작전 — "17:30, 퇴근까지 30분. 오늘은 반드시 정시에 나간다."

**주인공** (시작 화면에서 선택)
- **칼퇴준** (남, 입사 3개월 차): 삐뚤어진 넥타이, 동그란 안경, 백팩을 멘 채 달린다. 말버릇은 "저 오늘 약속 있어서요…!"
- **정시원** (여, 입사 3개월 차): 똑단발에 사원증 목걸이를 하고 에코백을 들었다. 말버릇은 "6시 땡이면 저는 없는 사람입니다!"

**무대**: 원래 "주식회사 야근상사"(가상 회사) 12층. 이름의 말장난이 개그 톤을 정한다.
게임 시계는 17:30에서 시작하고, 단계를 깰 때마다 HUD 시계가 18:00에 가까워진다. 5단계를 깨면 정확히 18:00:00에 타임카드를 찍는다.

## 5. 상관별 깜놀 공격

원칙: **겉모습은 새 개그 공격이지만, 판정은 기존 6가지 대응 중 하나로 정확히 대응된다.**
(점프 1~3단 / 슬라이드 / 레인 이동 / 드론형 = 높이 뛰지 말 것)
그래서 판정·물리 코드와 v8 기록 검증(golden 테스트)은 건드리지 않는다.
"깜놀"은 **연출**(갑툭튀 등장, 화면 흔들림, 효과음, 줌, 말풍선)로 만들고, 기존 "!" 예고(WARN_LEAD) 이상의 반응 시간을 항상 보장한다.

| 상관 | 공격 (보이는 모습) | 대응 (기존 판정) | 깜놀 연출 |
|---|---|---|---|
| 김대리 | 포스트잇 폭풍: "이것도 좀~" | 레인 이동 (guard) | 파티션 위로 고개가 쑥 올라오며 "어디 가?" |
| | 서류 더미 미끄러짐 | 점프 1단 (floor) | 서류 더미가 책상에서 와르르 무너진다 |
| | 아이스 아메리카노 쟁반 | 슬라이드 (high) | "커피 좀 사 와~" 쟁반이 머리 높이로 날아온다 |
| 박과장 | 최종_v3.xlsx 종이비행기 편대 | 드론형 (2단 이상 금지) | 복합기가 덜컹거리다 종이를 폭주한다 |
| | 결재판 부메랑 | 점프 2단 (beam) | 돌아오는 부메랑이 화면을 가로지른다 |
| | 복합기 용지 걸림 바닥 | 레인 이동 (drop) | 바닥에 "용지 걸림" 경고등 |
| 최팀장 | 회의실 문 벌컥 + "5분만!" | 레인 이동 (chaser) | 옆 문이 쾅 열리며 팀장이 따라온다 |
| | 화이트보드 돌진 | 점프 2단 (floor/beam) | 바퀴 소리가 "드르르륵" |
| | 레이저 포인터 (원작 오마주) | 슬라이드 (ceiling) | "여기 보세요~" 빨간 점이 줄줄이 |
| 오부장 | 퍼팅 골프공 | 점프 1단 (floor) | "나이스 샷!" 공이 굴러온다 |
| | "라떼는 말이야" 말풍선 장벽 | 슬라이드 (high) | 거대한 말풍선이 천장까지 부푼다 |
| | 엘리베이터 문 열리자 부장 | 레인 이동 (chaser) | "띵" 소리와 함께 문이 열리면 부장이 서 있다 |
| 한전무 | 결재 서류 회오리 | 드론형 | 서류가 소용돌이친다 |
| 윤이사 | 넥타이 채찍 | 점프 2~3단 (beam) | 넥타이가 고무줄처럼 늘어난다 |
| | 법인카드 "회식 가자" 손짓 | 레인 이동 (guard) | 카드가 반짝이며 길을 막는다 |
| 사장님 | 화상회의 거대 얼굴 "다들 수고 많아요~" | 슬라이드 (ceiling) | 천장 스크린이 갑자기 켜지며 거대한 얼굴이 나온다 |
| | 회전문 가속 | 레인 이동 (drop/chaser) | 회전문이 빙빙 빨라진다 |
| | 금일봉 봉투 비 | 점프 3단 (beam) + 코인 보너스 | 봉투가 쏟아진다. 높이 뛰면 보너스 |

보스 HP 막대는 **"퇴근 게이지"**로 바꾼다. 공격을 피할수록 상관이 "…그래, 가 봐"라며 지쳐 간다.
기존 구조(HP = 피한 공격 비율, 페이즈 = 구간)를 그대로 쓴다.

## 6. 예측불가 요소

1. **공격 변형**: 상관마다 같은 대응을 요구하는 공격 겉모습이 2~3종 있다. 판마다 시드로 골라서, 같은 단계라도 다른 개그가 나온다.
2. **돌발 사건** (단계마다 판당 1~2회, 시드로 종류와 타이밍 결정):
   - 청소 로봇 카트 / 택배 카트 질주 (레인 이동)
   - 동기의 "같이 퇴근하자!" 하이파이브 (보너스 코인, 피해 없음)
   - 정전 1.5초: 화면은 어두워지지만 장애물은 형광 윤곽선으로 보인다
   - 소방훈련 사이렌: 화면이 빨갛게 번쩍이고 공격 하나가 반대쪽에서 온다(기존 rear 패턴 + "!" 예고)
   - 사장님 깜짝 순시 사내방송: 모든 상관 대사가 "네 사장님!"으로 바뀌는 개그. 판정에는 영향 없음
3. **공정성 규칙** (깨면 버그로 본다):
   - 모든 돌발 사건과 공격은 기존 "!" 예고 시간 이상으로 미리 알린다
   - 돌발 사건은 기존 간격 규칙(spacing)을 통과한 비트에만 겉모습을 덧입힌다. 새 장애물을 끼워 넣어 간격을 좁히지 않는다
   - 결과 조작 금지(P3): 시드는 판 시작 시 정하고, 플레이어 입력에 따라 난이도를 몰래 바꾸지 않는다

## 8. 아트 (힉스필드)

**스타일 공통 규칙**: 밝은 한국 웹툰 코믹 치비 스타일(2~2.5등신 캐릭터), 굵은 외곽선, 파스텔 바탕에 형광 포인트 색. 과장된 표정과 만화 효과선을 쓰고 글자는 이미지에 넣지 않는다(대사는 게임이 그린다). 가상 회사 "야근상사"만 쓰고 실존 로고는 쓰지 않는다.

| 묶음 | 수량 | 내용 |
|---|---|---|
| 주인공 2명 | 각 9컷 | 달리기 4프레임, 점프, 슬라이드, 피격, 성공 포즈, 선택 화면 초상 (좌우 이동은 기울임으로 처리) |
| 상관 7명 | 각 3컷 | 대기, 공격, 지친 포즈(패배). 같은 사람이 컷신에도 나온다 |
| 무대 5곳 | 각 4장 | 벽 a/b/c, 바닥 (기존 복도 원근 렌더러에 텍스처로 입힌다) |
| 컷신 | 약 14장 | 오프닝 2, 보스 등장 7, 엔딩 2, 실패 1, 선택 화면 키아트 1, 타이틀 1 |
| 단계 카드 | 5장 | 단계 선택 화면 |
| 공격 소품 | 약 15장 | 포스트잇·서류·커피 쟁반·종이비행기·골프공·말풍선 등 |

- 합계 약 110장. 재시도 포함 **약 150~250크레딧 예상**(추정치, 잔액 2,760).
- 캐릭터 일관성은 기준 이미지 1장을 먼저 확정하고, 이후 컷은 그 이미지를 참조해 편집 생성(Nano Banana 2)하는 방식으로 맞춘다. 배경 제거 후 webp로 저장한다.
- 프롬프트와 모델은 `public/office/art/SOURCES.md`에 기록한다.
- **아트 디렉터 검수**: 스타일 통일, 플레이 크기에서의 가독성(장애물이 배경과 구분되는지)을 확인한다. 기준을 넘을 때까지 재생성한다.

## 9. 소리·연출

- 음악: 기존 절차적 신스를 장조·빠른 템포의 경쾌한 사무실 펑크 느낌으로 다시 조율한다.
- 효과음: 만화 효과음(뿅·쾅·띵·드르륵)을 절차적으로 합성한다(외부 에셋을 쓰지 않으니 라이선스 문제도 없다, P7).
- 상관 등장 시 깜놀 연출: 0.15초 화면 줌 + 흔들림 + 효과음 + 말풍선을 동기화한다. 기존 hit stop/timewarp를 재사용한다.
- 웹 진동(Vibration API)은 기존대로 쓴다. iOS 네이티브 진동은 이번 범위가 아니다.

## 10. 기술 구조

- **별도 진입점**: `office.html` → `src/office/main.ts`. 빌드 설정 `vite.office.config.ts`가 `dist/office/`로 출력한다.
  - 콘텐츠 모듈(`CHAPTERS`, `BOSSES`, `CUTSCENES`, 문구, 스킨)은 **빌드 시 별칭(alias)으로 칼퇴근판 데이터로 교체**한다. v8 코드 경로는 바뀌지 않는다.
- **5단계 캠페인**: 단계마다 3구간 + 끝에 보스가 나오는 **보스 단계 하나**로 구성한다. 5단계는 3구간에 전무·이사·사장님을 차례로 배치한다.
  - 지금 하드코딩된 "구역당 10스테이지 / s10 = 보스"를 설정값으로 일반화한다.
  - v8은 기존 값을 그대로 쓰고, 테스트로 결과가 같은지 확인한다.

## 13. 설계 검토 질문에 대한 결정 (작성자 판단 — 대표님 확인 대상)

1. **한 단계의 구조**: 한 단계는 **한 판(run) = 3구간**이다(v8 보스 스테이지와 같은 구조). 상관은 판 내내 공격하고, 구간마다 공격 페이즈가 하나씩 올라간다. "퇴근 게이지"는 그 단계 전체를 덮는다. 단계 카드와 별(★)은 단계 하나에 붙는다.
2. **판마다 바뀌는 것**: "예측불가"가 핵심 요청이므로 **판마다 새 시드로 장애물 배치까지 새로 짠다.** 단, 기존 생성기와 간격 검증(spacing)을 그대로 통과한 배치만 쓴다. 공격 겉모습, 돌발 사건 종류와 위치도 같은 시드로 정한다. 돌발 사건은 이미 생성된 비트에 겉모습만 덧입힌다(소방훈련 = 생성된 rear 비트, 카트 질주 = 생성된 레인 비트). 그래서 §6의 "비트를 새로 끼워 넣지 않는다" 규칙과 충돌하지 않는다. 판 시드는 저장해 두어 같은 시드면 같은 판이 재현된다. 봇 클리어 검증은 단계마다 시드 50개 이상으로 돌려 전부 깨는지 본다.
3. **동작 도입 순서**: 단계마다 새 동작은 1~2개만 도입하고, 처음 나올 때 기존 리듬 아이콘과 짧은 말풍선 힌트로 알려 준다. §5 공격 표는 이 순서에 맞게 배치한다.

   | 단계 | 새로 배우는 동작 |
   |---|---|
   | 1 | 점프 1단, 슬라이드, 레인 이동 (튜토리얼) |
   | 2 | 점프 2단, 드론형, 바닥 꺼짐(drop) |
   | 3 | 추격(chaser), 천장(ceiling/high) |
   | 4 | 점프 3단, 복습 |
   | 5 | 뒤에서 오는 공격(rear) + 전부 섞기 |

   §5 표의 공격이 아직 배우지 않은 동작을 요구하면, 같은 상관의 다른 공격 겉모습으로 대체한다.
4. **5단계 보스 셋**: 구간 1 = 한전무, 구간 2 = 윤이사, 구간 3 = 사장님. 구간마다 자기 게이지와 퇴장 대사가 있다. 보스 표시 코드(boss.ts, 연출 전용)를 "구간별 보스"를 지원하도록 확장한다. 판정에는 영향이 없다.
5. **실패와 시계**: 실패하면 **그 단계 처음부터** 다시 시작하고, 시계도 그 단계 시작 시각(17:30 + 6분 × (단계−1))으로 돌아간다. 깬 단계는 단계 선택 화면에서 다시 할 수 있다. 엔딩은 5단계를 처음 깼을 때 나온다. e2e는 단계를 순서대로 깨며 끝까지 가는 흐름으로 검증한다.
