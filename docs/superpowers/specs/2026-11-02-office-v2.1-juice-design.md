# 칼퇴근 대작전 v2.1 — 아이템·동작 연출/음향 + 장애물 가독성 보완

> 2026-11-02 · 기반 main d365004 (v2) · 대표님 요청: 아이템 획득 이펙트·음향, 점프/레인/슬라이드 음향, 힉스필드로 디자인·음향 제작, 애매한 장애물·그래픽 보완.
> 결정은 작성자(Claude) 판단.

## 1. 현재 상태
- 음향은 전부 코드 합성음(`src/audio/sfx.ts`), 녹음 샘플 재생 기능 없음. 점프·레인·슬라이드·코인 이벤트는 있으나 소리가 약해 체감이 없음.
- 아이템 획득은 소리 1종 + 작은 팝업뿐. 심리 지침(다중 감각 파이프라인: 시각·청각·촉각 동기화)에 미달.

## 2. 설계
### 2.1 음향 (힉스필드 오디오 생성, 샘플 재생)
- 오디오 레이어에 **샘플 플레이어**(fetch + decode, 캐시, 믹서 sfx 버스 경유, 음소거/볼륨/덕킹 준수) 추가. 칼퇴근판 `sfx` swap이 이벤트 → 샘플 파일(`public-office/sfx/<name>.ogg`, Safari용 `.m4a`)로 매핑. **파일 없음/디코드 실패 시 기존 합성음으로 대체**. v8은 합성음만(테스트로 고정).
- 동작: `jump1/2/3`(단계별 보잉·휘익), `land`, `slide`, `lane`(좌우 패닝 유지).
- 아이템: `pick-coin`(띵+반짝), `pick-shield`(버블 팝), `pick-slow`(얼음+빨대), `pick-heart`(냠), `pick-item`(수집품: 개수에 따라 음높이 상승 1.0→1.25), `pick-item-done`(목표 달성 징글).
- 피드백: `perfect`, `stamp`, `mission-ok`, `mission-miss`.
- 진동: 아이템 종류별 짧은 패턴, 미션 완료 더블 펄스(웹 Vibration API).

### 2.2 시각 연출 (칼퇴근 render)
- 코인: 금빛 스파클 + 아이콘이 HUD 코인 카운터로 날아감. 실드: 사원 주위 버블 링(지속·펄스, 깨질 때 팝). 슬로: 파란 얼음 비네트 + 컵 아이콘 펄스. 하트: 분홍 하트 상승. 수집품: 아이콘이 미션 칩으로 날아가며 「+1」, 목표 달성 시 별 폭발.
- 동작: 점프 단계별 도약 먼지 링(3단은 스파클 꼬리), 착지 눌림 먼지(작고 흰색 유지), 레인 이동 방향 줄무늬, 슬라이드 뒤꿈치 스파크.
- 전부 풀링(프레임당 할당 없음), 아이콘 없으면 대체.

### 2.3 장애물·그래픽 가독성 보완
- 모든 장애물/소품/아이템/이벤트를 실제 휴대폰 크기 맥락으로 캡처한 **카탈로그**를 만들고, 아트 디렉터가 "필요한 동작이 0.5초 안에 읽히는가"를 기준으로 심사 → 애매한 것은 그림(힉스필드) 또는 코드(크기·색·외곽선·동작 색 표시)로 수정.

## 3. 검증
- 테스트: 매핑·피치·대체 경로·v8 합성음 고정·파티클 수치. tsc, 두 빌드, golden 불변.
- e2e: 아이템 획득 시 FX/효과음 호출 확인(오디오 컨텍스트 스파이), 소리 파일 200, iOS Safari 언락 경로, 누락 파일 0.
