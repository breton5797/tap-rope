# LASER ESCAPE v7.1 — 요원 퀄리티 패스 (동작 · 이펙트 · 사운드)

요청: 요원 유닛 퀄리티와 동작 디테일 강화, 점프·슬라이드·이동·장애물 통과·피격 이펙트와 음향을 더 임팩트 있게.
결정(2026-10-28): 코드 리그 고도화 · 신스 레이어 강화 · 시네마틱 강도 · 요원 약 20% 확대.

**불변 조건**: 판정·박자·점수·리플레이(`src/game/session.ts` 판정 로직, `replay.ts`, `SIM_VERSION le-v7.1`)는 그대로.
모든 변경은 표현 계층(render / audio / feedback)과 게임 시계 배율뿐이며, 서버 재시뮬레이션 번들은 바뀌지 않는다.

## 1. 요원 그래픽 (render: `rig*.ts`, `agent.ts`, `skins.ts`)
- 크기 ×1.2 (그림만; 판정 영역·레인 폭 불변). 그림자·레인 아이콘 위치 재조정.
- 디테일: 헬멧 NVG 마운트와 렌즈 반사, 플레이트 캐리어 파우치·벨크로 패치(글자 없음), 무릎 패드, 장갑 손가락 마디, 부츠 밑창 홈.
- 명암: 어두운 배경에서 실루엣이 묻히지 않게 림라이트 강화 + 몸통 위쪽 키 라이트, 장비 금속부 스펙큘러.
- 2차 동작: 배낭·케이블·슬링 스트랩 지연 흔들림(스프링), 착지·피격 때 출렁임.
- 스킨 전체(요원·안드로이드·포로 등 기존 AgentLook) 동일하게 적용.

## 2. 동작 디테일 (render: `rig-poses.ts`, `agent.ts`)
| 동작 | 개선 |
|---|---|
| 달리기 | 상체 기울기·팔 스윙 강화, 발 디딤 순간 무게 실림(골반 하강), 속도에 따른 보폭 |
| 점프 | 0.06s 웅크림 예비동작 → 도약 시 몸 늘어남 → 정점 웅크림 → 착지 전 다리 뻗음 |
| 2·3단 부스트 | 몸 비틀기 + 회전, 단계별 회전량 차등 |
| 착지 | 무릎 굽힘 깊이 = 낙하 속도 비례, 0.12s 회복 |
| 슬라이드 | 진입 시 몸 낮추며 미끄러짐, 한 손 바닥 짚기, 탈출 시 튀어 오르기 |
| 레인 이동 | 이동 방향으로 몸 기울기(뱅킹) + 다리 교차 스텝, 끝 레인 부딪힘 시 휘청 |
| 장애물 통과 | PERFECT 통과 시 몸을 비트는 회피 자세(빔: 다리 접기, 천장: 고개 숙임) |
| 피격 | 뒤로 젖혀지는 반동 + 비틀거림 + 0.9s 무적 동안 깜빡임 대신 붉은 외곽선 점멸 |

## 3. 이펙트 (render: `effects.ts`, `post.ts`, 신규 `impact.ts`)
- 점프: 발밑 먼지 + 원형 충격 링, 부스트: 추진 불꽃 링(단계별 색·크기 증가).
- 착지: 지면 충격파 링 + 먼지 부채꼴, 3단 착지는 미세 화면 흔들림.
- 슬라이드: 바닥 마찰 불꽃 줄기(지속), 먼지 꼬리.
- 레인 이동: 모션 잔상(2~3 프레임 고스트) + 속도선.
- 장애물 통과: PERFECT = 레이저와 스치는 지점 스파크 + 짧은 하얀 섬광 / GOOD = 작은 스파크.
- 피격: 히트스톱 0.07s, 화면 흔들림, 붉은 비네트 0.4s, 색수차(RGB 분리) 0.25s, 파편·전기 스파크.
- 실드 막기: 청색 육각 실드 파편 + 링.
- 오버드라이브: 요원에 주황 오라 + 잔상.
- '동작 줄이기' 설정: 흔들림·색수차·잔상·슬로모션 끔, 섬광 강도 50%.

## 4. 게임 시계 연출 (game: 신규 `src/game/timewarp.ts`, `app.ts`)
- 히트스톱: 피격 0.07s 정지. 슬로모션: 보스 공격 PERFECT 회피와 3단 점프 PERFECT 때만 0.2s × 0.55배.
- 배율은 실제 시간 dt에만 곱한다(세션 시간 기준 판정·입력 기록은 그대로 → 리플레이 일치).
- 순수 함수 + 단위 테스트(누적·중첩·동작 줄이기).

## 5. 사운드 (audio: `sfx.ts`, `synth.ts`)
신스 레이어링: 트랜지언트(클릭/노이즈) + 바디(톤) + 저음(서브 킥) + 꼬리(필터 노이즈/잔향).
| 효과음 | 새 구성 |
|---|---|
| jump | 짧은 공기 휘익 + 장비 달그락 |
| boost | 상승 피치 추진음, 단계별 높아짐 |
| land | 서브 쿵 + 부츠 마찰, 높이 비례 |
| slide | 마찰 노이즈 스윕 + 금속 긁힘 |
| lane | 스테레오 휘익(이동 방향 패닝) |
| perfect / good | 금속성 핑 + 레이저 스침 지글거림 |
| zap(피격) | 서브 드롭 + 전기 크랙 + 왜곡 |
| 실드 | 유리질 깨짐 + 공명 |
- 동시 재생 제한(같은 효과음 50ms 이내 중복 억제), 마스터 리미터로 클리핑 방지.

## 6. 연결 (game: `feedback.ts`, `types.ts`)
- `EffectsApi`에 `impact(kind, opts)` 추가(점프·착지·슬라이드·레인·통과·피격·실드). 기존 burst/shake/flash 유지.
- 통과 이펙트는 판정 이벤트의 beatId로 장애물 종류를 찾아 위치(빔 높이·천장)를 정한다.
