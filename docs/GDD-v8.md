# LASER ESCAPE v8 — 플레이테스트 개선 (5인 테스트 → 수정 → 배포)

근거: 5개 테스트 리포트(디자인 · 레벨 · 재미 · 리텐션 · 품질), 2026-10-28.
원칙: 먼저 **점수·판정이 바뀌지 않는 묶음(A)** 을 끝내고, 점수 규칙이 바뀌는 **묶음(B)** 은 SIM_VERSION `le-v8` 한 번으로 모은다.
캠페인 생성기는 서버 시뮬레이터 번들에도 들어가므로, A에서 캠페인을 바꾸면 번들을 다시 빌드하고 **일일·무한 리플레이 결과가 바이트 단위로 같다는 골든 테스트**로 증명한다.

## 묶음 A — 점수 규칙 불변

### A1. 첫 판과 리듬 감각 (재미 P0-1, 레벨 P0-2, 디자인 P0-2)
- 리듬 레인의 점프·슬라이드 아이콘이 **이상적 입력 시각**(점프 −0.2s, 슬라이드 −0.2s)에 판정 링에 닿도록 오프셋한다. 링은 그 순간 맥동한다.
- 1-1 첫 판은 대화형 튜토리얼: 첫 장애물 앞에서 세계를 멈추고 오른쪽 절반에 "TAP" 손 아이콘 → 탭하면 진행. 첫 슬라이드·첫 레인 이동도 같은 방식(처음 1회).
- 조작 안내 카드는 터치 기기에서 키보드 키를 숨긴다. 훈련 카드는 카운트다운과 겹치지 않게 HUD 아래 한 줄로.
- 실패 화면: 나를 맞힌 장애물 아이콘 + 한 줄 팁("바닥 레이저 → 레이저가 발 앞에 오기 직전 탭"), 통계는 접기.

### A2. 화면 가독성 (디자인 P0-1, P1-4, P1-5)
- 세로 화면 카메라 1.35배 확대, 바닥선을 화면 62~65% 높이로, 타이밍 띠를 하단 안전 영역에 붙인다.
- 모든 장애물에 1.5px 외곽선 + 가산 발광, 바닥 빔 3~4px. 현재 레인 옅게 강조.
- 상단 HUD 압축(보스전에서는 SECTOR 바 숨김, 보스 HP만). 10~11px 글자 최소 12px.

### A3. 보스전 (레벨 P0-1, 재미 P0-3a) — 캠페인 전용
- 난이도 보정 d+0.08 → +0.04, 하자드 ×1.4 → ×1.25(최대 52), 픽업률 0.1 → 0.25, **보스 문마다 실드 보급 1개**.
- 페이즈 전환 대사 + 공격명("PHASE 2 — 기관포 연사"), 마지막 하자드 = 피니시 연출(슬로모 + 보스 폭발과 동시 착지).
- 보스 격파 전용 결과 카드(보스 이미지, "거점 제압" 배너).

### A4. 스테이지 다양성 (레벨 P0-3, P1-6, P1-7) — 캠페인 전용
- 일반 스테이지 동작 할당: jump·lane + 구역 핵심 동작 2~3 + 순환 2~3, 최대 ~7개.
- 새 동작 소개 스테이지 완화(lanejump 0.6→0.35, pulse 0.6→0.4, 3단 금지) + 첫 등장은 앞뒤 1.5s 여백.
- 각 구간 첫 하자드는 워밍업(1단·레인·슬라이드).
- 가드 테스트: 할당 하자드 ≤ 30%, 완벽 봇 무피격 클리어 유지, 일일·무한 골든 불변.

### A5. 다시 할 이유 (리텐션 P0-1~3, P1-1, P1-4)
- **저장 보존**: `navigator.storage.persist()`, 저장 내보내기/가져오기 "이전 코드"(설정 화면), 더 새 버전 저장은 지우지 않고 보존 + 안내(품질 P1-4).
- **일일 루프**: 연속 일수 표시(일일 버튼·결과), 연속 보상(1·3·7일 ₵), 기록 갱신 없는 클리어도 성공 톤.
- **경제**: 첫 클리어 +10₵(보스 +30), 새 별 +5₵, 업적 +20~50₵, 첫 임무 보상 60₵. 사용처: 스킨별 색상 변형, 착지 링·레이저 잔상 색(v7.1 임팩트 훅), 결과 카드 프레임.
- **목표 표시**: 타이틀에 "다음 목표" 한 줄, 업적 진행도(3/10), 결과 화면에 ★3 조건("무피격 · PERFECT 60%")과 "다음 순위까지 −N점", 결과·지도에서 랭킹 바로가기.
- **공유**: 결과 카드 이미지 + `navigator.share`, 도전 링크 `?endless=<seed>&vs=<score>`.

### A6. 품질·접근성 (품질 P1-1~4, P2)
- 늦게 도착한 랭킹/제출 응답은 화면이 바뀌었으면 무시. window blur·pagehide에도 일시정지.
- 업적 토스트 큐(한 번에 하나, 2개 이상은 "업적 N개 달성"), 카운트다운·브리핑 중 금지, 결과 화면에서는 카드 안 배지로(디자인 P0-3).
- 지도 구역 탭 잘림 수정, 설정 토글 ON/OFF 표기, 가로 화면 타이틀 스크롤, 확대 허용, 모달 포커스, 플레이 중 aria-live 음소거, 잠긴 탭 aria-disabled.
- iOS 홈 아이콘 PNG(180/192/512) + 공유 미리보기 이미지(og), 등록은 랭킹·제출 시점으로 지연(부팅 시 자동 등록 중단).

## 묶음 B — 점수 규칙 변경 (SIM_VERSION `le-v8`, 서버 시뮬레이터 재배포)
- **판정 3단계**: 이상적 입력 시각 기준 PERFECT ±50ms / GREAT ±110ms / GOOD(통과 창 나머지). 통과·실패 기준은 그대로. ★3 = 무피격 + PERFECT ≥ 60%.
- **콤보 티어**: x1 → 10콤보 x1.5 → 25 x2 → 50 x3 (오버드라이브와 별도).
- **무한 모드 후반**: 15구간 이후에도 BPM 상한 140 → 160까지 완만히, 구간마다 변형(미러·밀집).
- 기존 기록과의 공정성: 랭킹 보드에 `le-v8` 이후 기록만 표시하는 새 시즌 보드(무한 전체·주간·일일), 이전 기록은 보관.
