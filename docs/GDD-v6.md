# LASER ESCAPE v6 — 시네마틱 잠입 리얼리즘 (승인: 2026-10-26)

v5(`docs/GDD-v5.md`)의 게임플레이·판정·생성기·캠페인·저장은 **그대로**. 바뀌는 것은 겉모습·말투·소리.
사용자 피드백: "너무 유아틱하다. 실제 느낌이 나고 현실적이게." → 방향: 시네마틱 잠입(미션 임파서블·스플린터 셀),
실제 비율 요원, 전체 톤 개편(화면 + UI + 문구 + 사운드).

## 1. 아트 원칙 (모든 팀 공통)
- **금지**: 큰 머리·동글동글 비율, 파스텔·사탕색, 하트/별 장식, 귀여운 표정(눈웃음·볼터치), 말풍선 말투, 둥근 Jua 글꼴, 이모지.
- **색**: 어두운 중성(차콜·건메탈·콘크리트) 기반. 강조는 레이저 레드(#FF2A3A), 경고 앰버(#FFB020), 시스템 청록(#3FE0D0) 세 가지만.
  장면 색보정은 청록 그림자 + 주황 하이라이트(시네마틱 teal/orange), 비네트.
- **빛**: 화면 안의 광원(천장 등, 비상등, 레이저, 모니터)이 주변을 실제로 밝힌다. 레이저는 가늘고 밝은 코어 + 블룸, 연기 속에서 산란.
- **재질**: 콘크리트, 도장 강철, 금속 그레이팅, 배관, 케이블 트레이, 스텐실 표지(영문·숫자 코드).
- **모션**: 무게감. 과장된 스쿼시·스트레치 금지, 착지 시 무릎 굽힘·관성.
- **성능 예산**: iPad 7세대(A10)에서 60fps 목표. 블룸·그레인·빛줄기는 미리 구운 스프라이트/타일로. 캔버스 메모리 iPhone ≤ 35MB,
  iPad ≤ 55MB(전환 중 포함, v5 수준). 모션 줄이기: 흔들림·그레인·플래시·색수차 끔.

## 2. 사진풍 아트 에셋 (art 팀 제작 → `public/art/`, render가 사용)
로컬 FLUX.1-schnell(mflux)로 생성 → 선별 → 크롭/보정 → WebP. 총합 ≤ 4MB. 파일명 고정(코드가 참조):
| 파일 | 크기(px) | 내용 |
|---|---|---|
| `wall-{t}-{a,b,c}.webp` (t = 0..3) | 1024×640 | 테마 t의 뒷벽 **정면 입면도**(원근 없음, 수평 수직선), 사람·글자 없음. 좌우 끝 64px은 단색에 가까운 구조물(이음매를 기둥으로 가림) |
| `floor-{t}.webp` | 1024×512 | 위에서 내려다본 바닥 재질, **좌우 이음매 없이 반복** 가능(가공) |
| `ceiling-{t}.webp` | 1024×256 | 천장 위 설비대(덕트·배관·케이블 트레이) 정면 입면도, 좌우 반복 가능 |
| `title.webp` | 1080×1920 | 타이틀 키아트: 어두운 복도, 붉은 레이저 격자, 실루엣 요원, 상단 1/3은 로고용으로 어둡게 |
| `zone-{0..9}.webp` | 640×360 | 구역 카드/브리핑용 장면 컷(구역 표 §2.1) |
테마: 0 경비 초소(콘크리트·철조망 너머 탐조등·보안 게이트), 1 연구소(백색 패널·유리·서버랙), 2 감옥(철창·강화문·감시창),
3 공장·수로(배관·밸브·증기·녹슨 강철).
### 2.1 공통 프롬프트 스타일
`cinematic photograph, dim high-security facility interior, <subject>, straight-on flat frontal elevation, orthographic,
symmetrical, no people, no text, no logos, moody teal shadows, warm amber practical lights, subtle haze, 35mm film,
highly detailed, realistic materials` + 네거티브 개념은 프롬프트에서 배제 문구로. 시드 기록(`public/art/SOURCES.md`).
장면 변형(night/dark/alarm/steam/dawn)은 **이미지가 아니라** render의 조명·색보정으로 만든다.

## 3. 요원·인물 (render)
- 성인 비율 ≈ 7.5등신, 화면 키 약 88px(가운데 레인). 관절 리그(골반·척추·목·어깨·팔꿈치·손·고관절·무릎·발목) 기반 절차 애니메이션:
  달리기 사이클(팔다리 반대 위상, 상체 앞기울기, 머리 안정), 점프 도약·체공·2단(앞구르기 회전)·3단(공중제비), 슬라이딩(무릎 슬라이드, 손 짚기),
  급강하, 레인 이동(상체 기울임), 피격(몸 젖힘), 대기(숨쉬기).
- 렌더: 실루엣 단색 위에 면 단위 음영(키라이트 위·앞, 림라이트 장면 색), 장비 디테일(전술 조끼·벨트·홀스터·장갑·야간투시경·이어피스).
- 스킨 6종(ID 유지, 이름·디자인 변경): kid=에이전트 K(검정 전술복) · cat=블랙캣(무광 스텔스 수트) · bunny=해커(후드+백팩 장비) ·
  robot=R-7(전투 안드로이드, 금속 외피) · ninja=섀도우(복면, 짙은 남색) · astro=특수부대(올리브 전투복·헬멧).
- 포로(2부 호위): 주황 수감복의 성인 과학자, 같은 리그.

## 4. 장애물·환경 (render)
- 레이저: 바닥/천장 발사 장치(금속 하우징, 렌즈, 상태등), 빔 = 밝은 흰빛 코어 + 붉은 블룸, 아지랑이 흔들림, 연기 산란. 슬라이드용은 청록 대신 **붉은 계열 유지 + 높이로 구분**(현실감) — 단, 점프/슬라이드 구분이 흐려지지 않게 발사 위치(바닥/천장)·높이 표시선 강조.
- 드론: 무광 쿼드콥터 + 아래 스캔 빔(레인마다). 경비로봇: 2족 무장 감시 로봇(장갑판, 붉은 센서). 낙하: 크레인 집게의 강철 화물(체인·흔들림).
  추격: 탐조등 단 쿼드콥터. 문: 방폭문(두께, 위험 줄무늬, 유압 피스톤, 열릴 때 증기).
- "!" 경고: 앰버 삼각 경고 표식 + 바닥 레이저 조준 링(유치한 말풍선 금지).
- 화면 후처리: 색보정, 비네트, 필름 그레인(아주 약하게, 미리 구운 노이즈 타일), 먼지 입자, 빛줄기, 피격 시 짧은 색수차·적색 플래시.
- 레인 HUD 아이콘: 아이콘 폰트 느낌의 단색 선 아이콘(전술 HUD).

## 5. UI·문구 (ui)
- 글꼴: 본문 `IBM Plex Sans KR`(400/600), 숫자·영문 라벨 `Rajdhani`(600/700) — Google Fonts(현행 Jua와 같은 방식). Jua 제거.
- 패널: 반투명 다크 글래스(blur), 1px 라인, 모서리 2~4px, 앰버/청록 강조. 사탕형 그라디언트 버튼·두꺼운 외곽선·흔들리는 장식 제거.
- 화면: 로딩(진행 바) → 타이틀(키아트 + 로고 "LASER ESCAPE / 레이저 탈출작전") → 작전 지도(구역 카드 = zone 이미지) → 브리핑(기밀 문서) →
  HUD(전술 오버레이) → 결과 = 작전 보고서(성공/실패, 정확도, 연속, 획득 자금).
- 문구 말투: 짧은 작전 보고체. 예) "작전 개시", "임무 완료", "임무 실패 — 재투입?", "경보: 후방 접근", "레인 이탈 필요".
  판정 팝업: PERFECT / GOOD / MISS 영문 유지(전술 HUD 스타일), 콤보 "x20 CHAIN". 튜토리얼 문구도 같은 말투(느낌표 남발 금지).
- 코인 → "자금(₵)" 표기, 하트 → 방탄 게이지(실드 칸 3개).

## 6. 문구 데이터 (core)
- SKINS 이름 §3, CHAPTERS subtitle·briefing을 작전 보고체로, 단계 이름 100개 중 유치한 것 교체(예: '쥐들의 지름길', '실험체 탈출?', '숨을 고르며',
  '잃어버린 금화', '물방울 리듬'), WORLDS 이름·부제 점검. 게임플레이 수치·ID·저장 키 불변.

## 7. 사운드 (audio)
- 음악: 다크 신스 — 베이스 펄스(8분), 킥/스네어 대신 저음 타격·하이햇 틱, 긴장 패드, 테마별 음색. 피버 = 템포 동일, 레이어 추가.
- 효과음: 점프(천 스침+발 구름), 착지(묵직한 발소리), 레이저 험/발사(전기 지글), 피격(전기 충격+왜곡), 레인(바람 가름), 경고(낮은 2톤 경보),
  문(유압+증기), 픽업(금속 클릭), 클리어(낮은 스팅어). 전부 절차 합성.

## 8. 통합 (lead)
- 부팅: `renderer.load(progress)` 동안 `ui.showLoading(p)` → 완료 시 타이틀. 실패해도 진행(절차 그림 대체).
- vite: `public/art/*.webp`를 서비스워커 precache에 포함, 캐시 버전은 파일 내용 해시 포함.
